# Password Strength Checker in C++

## 📌 Project Overview

Password Strength Checker is a simple C++ program that analyzes a password and determines its strength based on different security criteria.

The program checks whether the password contains:

* At least 8 characters
* Uppercase letters
* Lowercase letters
* Numbers
* Special characters

Based on these conditions, the password is classified as **Weak, Medium, or Strong**.

## 🛠️ Technologies Used

* **Language:** C++
* **IDE:** Dev-C++
* **Concepts:** Strings, Loops, Conditional Statements, Character Functions

## ⚙️ Features

* Checks password length
* Detects uppercase letters
* Detects lowercase letters
* Detects numbers
* Detects special characters
* Calculates a strength score
* Displays the final password strength

## ▶️ How to Run

1. Open **Dev-C++**.
2. Create a new C++ source file.
3. Copy the program code into the file.
4. Save it as `password_checker.cpp`.
5. Compile and run the program.
6. Enter a password when prompted.
7. View the password analysis and strength result.

## 📊 Strength Criteria

| Criteria          | Score |
| ----------------- | ----: |
| Length ≥ 8        |     1 |
| Uppercase letter  |     1 |
| Lowercase letter  |     1 |
| Number            |     1 |
| Special character |     1 |

**Strength Levels:**

* **Weak:** 0–2 points
* **Medium:** 3–4 points
* **Strong:** 5 points
